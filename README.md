# SkyCast - Weather Forecast Application

SkyCast is a simple weather forecast application built using HTML, CSS and JavaScript.

## Features

- Search weather by city name
- Get weather using current location
- Display today's temperature and weather condition
- Show humidity, wind speed and feels-like temperature
- 5-day weather forecast
- Celsius and Fahrenheit temperature toggle
- Recently searched cities
- Weather icons based on weather conditions
- Dynamic background for different weather conditions
- Custom error messages for invalid searches
- Extreme temperature warning

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API
- Local Storage
- Geolocation API

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Search for any city to view its weather.

## Project Files

- `index.html` - Application structure
- `style.css` - Styling and responsive design
- `script.js` - Weather API and application functionality
- `.gitignore` - Files ignored by Git
- `COMMIT_HISTORY.txt` - Project commit record

## API

Weather data is provided by Open-Meteo.
